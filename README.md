----------Library Kiosk System----------

A Flask-based system for managing a school library with RFID-based borrowing/returning, online portal access, and Arduino integration.

----------Features----------

- RFID card-based login via Kiosk
- Book borrowing & returning
- Admin & user dashboard
- Online book reservations
- Receipt printing via thermal printer
- Syncs with online portal

----------Tech Stack----------

- Python (Flask)
- MySQL (Hosted on Railway)
- HTML, CSS, JavaScript
- Arduino + MG996R Servo Motor
- Render (for deployment)
